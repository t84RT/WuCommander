## 📖 项目简介

**WuCommander** 是一款基于 Python + Tkinter 开发的跨平台串口调试工具，由 **小吴同学电气设计（t84RT）** 个人维护并免费开放。它不仅仅是一个简单的串口收发器，更是一个集成了**实时数据统计**、**十六进制/文本双模式显示**、**定时轮询发送**、**日志导出**、**二维码社区引流**以及**智能悬浮播报**的综合性工作台。

无论您是调试 PLC、STM32、ESP32，还是进行物联网网关数据监控，WuCommander 都能为您提供清晰、稳定、高效的操作体验。同时，软件内置了作者的技术社区链接，方便您获取更多工业自动化与嵌入式开发资源。

## ✨ 功能特性

### 核心通信能力
- **全参数串口配置** —— 支持端口、波特率（1200 ~ 921600）、数据位（5~8）、停止位（1/1.5/2）、校验位（N/E/O/M/S）实时调整。
- **一键打开/关闭** —— 快速连接与断开，状态指示灯实时反馈。
- **异步线程读取** —— 独立接收线程，界面永不卡顿。
- **数据收发计数** —— 实时统计发送/接收字节总数，并显示运行时长。

### 数据展示与处理
- **双模式接收显示** —— 支持 **ASCII 文本**（UTF-8 解码）与 **十六进制（Hex）** 显示，一键切换。
- **暂停接收** —— 临时冻结接收区，便于分析历史数据。
- **清空与导出** —— 一键清空接收区，或将全部日志导出为 `.txt` 文件。
- **自动滚屏** —— 新数据自动滚动到最下方。

### 发送功能
- **文本/十六进制发送** —— 支持普通字符串（自动追加 `\r\n` 可选）和原始 Hex 字节流（如 `01 02 FF`）。
- **定时发送** —— 自定义间隔（毫秒级），循环发送当前发送区内容，适用于轮询指令测试。
- **快捷键发送** —— `Ctrl + Enter` 快速发送当前输入。

### 用户体验与视觉
- **滚动跑马灯** —— 顶部实时滚动作者品牌标语，增强辨识度。
- **二维码关注支持** —— 若同目录下放置 `公众号.png` 和 `小程序码.png`，将显示缩略图，**点击即可放大预览**，方便扫码关注。
- **智能悬浮播报** —— 右下角固定悬浮窗，每 5 秒轮播显示作者联系方式、工具版本、服务领域等动态信息，不干扰主界面操作。
- **作者信息栏** —— 底部集成 GitHub、个人站、B站、CSDN、博客园等一键跳转链接。

### 跨平台兼容
- 基于 Python 标准库 + pyserial，支持 **Windows / Linux / macOS**。
- 自动检测系统可用串口列表，即插即用。

## 🚀 安装与运行

### 环境要求
- Python 3.7 及以上版本
- 操作系统：Windows 7+ / Linux (X11) / macOS

### 依赖库
```bash
pip install pyserial
```
可选依赖（用于二维码图片显示与缩放）：
```bash
pip install Pillow
```
> 若未安装 Pillow，二维码区域将仅显示提示文字，不影响核心串口功能。

### 获取源码
```bash
git clone https://github.com/t84RT/WuCommander.git
cd WuCommander
```

### 运行
直接执行最新版本（V3）：
```bash
python WuCommanderV3.py
```
也可运行 V1 / V2 版本，但推荐使用 V3 以获得最佳体验。

### 打包为独立 EXE（可选）
使用 PyInstaller 打包：
```bash
pip install pyinstaller
pyinstaller -F -w WuCommanderV3.py --name WuCommander
```
> 打包后可将 `公众号.png` 和 `小程序码.png` 放置于同目录下，以启用二维码展示。

## 🧭 使用指南（详细操作）

### 1. 串口连接
- 从 **端口** 下拉框中选择您的设备（若未显示，点击 **刷新** 重新扫描）。
- 按需调整 **波特率**、**数据位**、**停止位** 和 **校验位**（默认 115200-8-N-1）。
- 点击 **打开串口**，状态变为绿色“已连接”，同时 **打开串口** 按钮文字变为 **关闭串口**。
- 若打开失败，会弹出错误提示，请检查端口是否被占用或参数是否正确。

### 2. 数据接收
- 所有接收到的数据实时显示在 **接收区** 中。
- 默认以文本（UTF-8）方式显示，若勾选 **十六进制显示**，将以 Hex 格式（如 `01 02 FF`）呈现，每 16 字节自动换行。
- 点击 **暂停接收** 可临时冻结显示（但后台仍继续接收，只是不更新界面），再次点击恢复。
- 点击 **清空接收** 会清除所有已显示数据，并重置发送/接收计数。
- 点击 **导出日志** 可将当前接收区全部内容保存为 `.txt` 文件（支持任意编码）。

### 3. 数据发送
- 在 **发送区** 输入要发送的内容。
  - 若 **十六进制发送** 未勾选，则按普通字符串发送（如 `Hello`），并可选择是否自动追加 `\r\n`（发送新行）。
  - 若勾选 **十六进制发送**，则输入应类似 `01 02 FF 0A`（空格自动忽略），长度必须为偶数个十六进制字符。
- 点击 **发送** 或按下 `Ctrl+Enter` 立即发送当前输入。
- **定时发送**：点击 **定时发送** 按钮，工具将按照 **间隔(ms)** 设定的毫秒数循环发送当前发送区内容；再次点击该按钮停止定时。定时发送时，按钮旁会显示绿色“定时运行中”。

### 4. 辅助功能
- **跑马灯**：顶部条幅自动滚动显示项目名称与标语，无需操作。
- **二维码关注**：
  - 若 `公众号.png` 和 `小程序码.png` 存在于程序同目录，则会在“关注支持”区域显示缩略图。
  - **点击缩略图** 会弹出放大窗口，便于手机扫码。窗口点击任意处即可关闭。
  - 若未找到图片，仅显示文字提示，不影响其他功能。
- **悬浮播报**：
  - 主窗口右下角固定悬浮小窗，内容每 5 秒轮换一次，包括小程序引导、邮箱联系、版本信息等。
  - 悬浮窗始终置顶，但透明度较高，不会过分遮挡主界面。

### 5. 状态监控
- 底部状态栏实时显示：
  - **串口状态**（运行中 / 已断开）
  - **累计发送字节数**
  - **累计接收字节数**
  - **从打开串口开始的运行时长**（秒）
- 状态每秒自动刷新。

### 6. 作者与社区
- 底部信息栏提供作者名称、邮箱，以及一键打开以下站点的链接（点击蓝色文字）：
  - GitHub
  - 个人技术网站
  - B站空间
  - CSDN博客
  - 博客园
- 所有链接均通过系统默认浏览器打开。

## 🛠️ 技术架构

- **前端**：Tkinter + ttk（轻量级，无需额外 GUI 库）
- **串口通信**：`pyserial` 异步读写，使用独立线程 + 队列（`queue.Queue`）传递数据，确保主线程不阻塞。
- **图片处理**：Pillow（可选）用于加载和缩放二维码图片。
- **跨平台**：纯 Python 实现，借助 `serial.tools.list_ports` 自动适配不同系统。
